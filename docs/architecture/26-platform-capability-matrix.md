## 26.3 Verification protocol
Each adapter module carries `VERIFIED_AT = "2026-10-08"` and a link list; CI fails a release if any adapter's verification date is > 180 days old without an explicit override; the Admin → Integrations page displays the date. Items marked **?** above are tracked in `docs/platforms/open-questions.md` and must be resolved before the related feature is enabled for users.
